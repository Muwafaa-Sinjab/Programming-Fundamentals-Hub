# 10 - OOP as it Should Be (Concepts)

## Overview

This course introduces Object-Oriented Programming in C++. It explains the change from procedural programming to object-oriented programming. It covers classes, objects, memory layout, encapsulation, constructors, inheritance, polymorphism, abstraction, and other C++ OOP features.

## Main Topics

### Classes, Objects, and Memory

Learn how classes work as blueprints and how objects use memory at runtime.

The course covers:

* Data members and their memory.
* Shared function members between objects.
* `private` and `protected` access.
* `Get` and `Set` property methods.

### Encapsulation

Learn how to keep data and functions together and control access to internal data.

The course uses `private` members with `public` Get and Set methods to control data access.

### Abstraction

Learn how to expose important operations while hiding the internal implementation.

The course uses high-level methods while keeping internal state and logic hidden.

### Constructors and Destructors

Learn about object creation and cleanup using:

* Default constructors.
* Parameterized constructors.
* Copy constructors.
* Destructors.
* `delete` for manual memory deallocation.
* Cleanup when an object leaves its scope.

### Inheritance

Learn how classes can inherit from other classes to reuse code.

The course covers:

* Single Inheritance.
* Multi-Level Inheritance.
* Hierarchical Inheritance.
* Multiple Inheritance.
* Hybrid Inheritance.
* `public`, `protected`, and `private` inheritance visibility.
* Method overriding.

### Upcasting and Downcasting

Learn about pointer relationships between base and derived classes.

The course covers Upcasting and Downcasting.

### Polymorphism

Learn how different object types can be used through a common interface.

The course covers:

* Early and Static Binding.
* Late and Dynamic Binding.
* Function Overloading.
* Operator Overloading.
* Method Overriding.
* `virtual` functions.
* Virtual tables (`vtables`).

### Abstract Classes

Learn how abstract classes define required behavior using pure virtual functions.

The course covers pure virtual functions using `= 0`.

### Static Members and This Pointer

Learn about:

* `static` members and class-level lifetime.
* The `this` pointer and its scope.

### Friend Classes and Functions

Learn how `friend` classes and functions can access class members.

### Nested Structures and Classes

Learn how structures and classes can be placed inside other classes.

### Header Files and Object Collections

Learn how to organize code using header files and `#pragma once`.

The course also covers object collections using:

* Dynamic arrays.
* `std::vector`.

## Key Takeaways

* Understand the transition from procedural programming to Object-Oriented Programming.
* Understand classes, objects, and memory layout.
* Apply Encapsulation using access specifiers and Get/Set methods.
* Understand Abstraction and how to hide internal implementation.
* Use constructors and destructors for object lifecycle management.
* Understand different Inheritance models.
* Understand Upcasting and Downcasting.
* Understand Polymorphism and Dynamic Binding.
* Use `virtual` and pure virtual functions.
* Understand abstract classes and behavioral contracts.
* Work with `static` members, the `this` pointer, and `friend` classes and functions.
* Organize C++ code using header files.
* Store objects using dynamic arrays and `std::vector`.

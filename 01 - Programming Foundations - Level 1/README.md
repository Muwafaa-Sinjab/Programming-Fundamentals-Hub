# 1 - Programming Foundations Level 1

## Overview

This course builds basic programming foundations before writing code. It explains data, computer parts, memory, number systems, networks, programming languages, and how programs are executed.

## Main Topics

### Data and Information

Learn the difference between data, information, knowledge, and wisdom. The course explains how raw data can become useful information and knowledge.

### Computer Architecture

Learn about computer hardware, the CPU, memory, and input and output functions. The course also explains how data is stored and represented in the computer.

### Number Systems

Learn about Binary, Hexadecimal, and Octal number systems. The course also covers Bit, Nibble, Byte, and common storage units such as KB, MB, GB, and TB.

### Networks

Learn the basic ideas of connecting devices, communication protocols, and data transfer.

### Programming Languages

Learn about programming language levels, programming language history, and the difference between high-level and low-level languages.

### Compiler and Interpreter

Learn the basic difference between a Compiler and an Interpreter and how they execute program code.

### Program Execution

Learn about programming environments and how a program moves from written code to machine execution.

### C++

Learn why C++ is used as a starting language for algorithmic thinking and understanding memory management.

### Basic Programming Concepts

Learn about arithmetic and logical operations, operation priorities, variables, constants, and data types.

### Programmer Calculator

Learn how to use a Programmer Calculator to work with different number systems.

## Key Takeaways

* Understand the difference between data, information, knowledge, and wisdom.
* Understand basic computer components, memory, and the CPU.
* Work with Binary, Hexadecimal, and Octal number systems.
* Understand Bit, Nibble, Byte, and storage units.
* Understand basic networks and data transfer.
* Understand programming languages, Compilers, and Interpreters.
* Understand how programs are executed.
* Understand basic operations, variables, constants, and data types.
* Understand why C++ is used as a starting point for programming.

# 06 - Introduction to Programming Using C++ Level 2

## Overview

This course covers foundational and intermediate C++ programming concepts. It focuses on debugging, memory, pointers, functions, dynamic memory, vectors, file operations, and error handling.

## Main Topics

### Debugging

Learn how to find and understand different types of errors:

* Logical Errors.
* Syntax Errors.
* Runtime Errors.

The course also covers debugging tools and controls:

* `F5` — Run / Continue.
* `F10` — Step Over.
* `F11` — Step Into.
* `Shift + F11` — Step Out.
* `Breakpoints`.
* `Autos`.
* `QuickWatch`.
* `Call Stack`.
* `Call Hierarchy`.

### Custom Libraries and Header Files

Learn how to create reusable code using custom `.h` header files and custom `namespaces`.

### Conditional Statements and Input Validation

Learn how to use the ternary operator `? :` for shorter conditional statements.

The course also covers input validation using:

* `cin.fail()`
* `cin.clear()`
* `cin.ignore()`

### Functions

Learn about different function features, including:

* Function declarations and definitions.
* Default parameters.
* Function overloading.
* Recursion.
* Recursion performance characteristics.

### Memory and Variables

Learn how variables use memory and how their lifetime works.

Topics include:

* `static` variables.
* `auto` types.
* System registers.
* Memory addresses in Hexadecimal.
* Stack and Heap memory.

### References and Pointers

Learn how to work with memory addresses, references, and pointers.

Topics include:

* Call By Value.
* Call By Reference using `&`.
* Aliases.
* Dereferencing using `*`.
* Pointer arithmetic.
* Array indexing using pointers.
* Structure pointers using `ptr->member`.
* `void*`.
* `static_cast`.

### Dynamic Memory

Learn how to allocate and release memory dynamically.

Topics include:

* `new`
* `delete`
* `new[]`
* `delete[]`
* Dynamic arrays.
* Stack vs. Heap allocation.

### Vectors

Learn how to work with dynamic vectors.

Topics include:

* Ranged loops.
* `push_back`.
* `pop_back`.
* `clear`.
* `.at()`.
* Vector size and capacity.
* `vector<struct>`.
* Iterators.

### File Operations

Learn how to work with text files using `fstream`.

The course covers:

* Write Mode using `ios::out`.
* Append Mode using `ios::app`.
* Read Mode using `ios::in`.
* Updating text records.
* Deleting file lines.

### Output Formatting and Utilities

Learn different tools for working with output and text.

Topics include:

* `printf` format specifiers such as `%d`, `%.3f`, and `%s`.
* Output alignment using `setw`.
* String manipulation.
* `cctype` utilities.
* Date and time handling using `<ctime>`.

### Exception Handling

Learn basic exception handling using:

* `try`
* `catch`

## Key Takeaways

* Understand how to find and solve different types of programming errors.
* Use debugging tools to follow program execution.
* Create custom libraries and header files.
* Use functions, default parameters, overloading, and recursion.
* Understand memory addresses, references, and pointers.
* Work with Stack and Heap memory.
* Allocate and release dynamic memory using `new` and `delete`.
* Work with dynamic arrays and vectors.
* Read, write, update, and delete text file records.
* Use exception handling with `try` and `catch`.
* Work with strings, character utilities, and date and time structures.
* Format program output using `printf` and `setw`.

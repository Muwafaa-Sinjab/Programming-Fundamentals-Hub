# 3 - Introduction to Programming Using C++ Level 1

## Overview

This course introduces programming using C++. It covers the basic syntax of C++, variables, data types, operators, functions, arrays, conditions, and loops. It also introduces structures and enumerations.

## Main Topics

### C++ Basics

Learn the basic structure and syntax of C++ programs.

Topics include:

* `#include <iostream>`
* `main()`
* Semicolons `;`
* Output using `cout`
* New lines using `\n` and `endl`
* Escape sequences
* Comments

The course also explains why C++ is used as a starting language and covers its high performance, memory control, and support for Procedural and Object-Oriented Programming.

### Variables, Data Types, and Input

Learn how to store and work with data using variables.

Topics include:

* `int`
* `float`
* `double`
* `char`
* `bool`
* `string`
* `short`
* `long`
* `signed`
* `unsigned`
* Input using `cin`
* Data type conversion using `stoi`, `stof`, `stod`, and `to_string`

### Operators and Mathematical Functions

Learn how to use arithmetic, comparison, and logical operators.

Topics include:

* Arithmetic operators: `+`, `-`, `*`, `/`, `%`
* Increment and decrement: `++`, `--`
* Prefix and Postfix
* Relational operators
* Logical operators: `&&`, `||`, `!`
* Mathematical functions from `<cmath>`:

  * `sqrt()`
  * `round()`
  * `pow()`
  * `ceil()`
  * `floor()`
  * `abs()`

### Structures and Enumerations

Learn how to organize related data using:

* `struct`
* `enum`
* Nested Structures
* Nested Enums

### Functions

Learn how to create and use functions and procedures.

Topics include:

* Functions that return values.
* Procedures using `void`.
* Local and Global variables.
* Variable scope.
* Global scope using `::`.
* Passing parameters By Value.
* Passing parameters By Reference.

### Arrays

Learn how to store multiple values of the same data type in an array.

Topics include:

* Array indexes starting from `0`.
* Using arrays with functions.
* Passing arrays to functions.
* Arrays of Structures.

### Conditional Statements

Learn how to make decisions in a program using:

* `if`
* `else if`
* `else`
* `switch`
* `case`
* `break`

### Loops

Learn how to repeat code using:

* `for`
* `while`
* `do ... while`

The course also covers:

* `break` for stopping a loop.
* `continue` for skipping the current iteration.

## Key Takeaways

* Understand the basic structure and syntax of C++ programs.
* Work with variables, data types, and user input.
* Use arithmetic, relational, and logical operators.
* Use mathematical functions from `<cmath>`.
* Understand Structures and Enumerations.
* Create functions and procedures.
* Understand Local and Global variable scope.
* Understand passing parameters By Value and By Reference.
* Work with arrays and arrays of structures.
* Use conditional statements to make program decisions.
* Use `for`, `while`, and `do ... while` loops.
* Use `break` and `continue` to control loops.
* Understand the basic reasons for using C++ and its support for Procedural and Object-Oriented Programming.

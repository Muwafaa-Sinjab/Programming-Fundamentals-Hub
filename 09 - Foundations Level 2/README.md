# 09 - Foundations Level 2

## Overview

This course introduces the basic concepts of computer networks and the Internet. It covers network types, servers, network devices, IP addresses, protocols, web technologies, data exchange, and 3-Tier Architecture.

## Main Topics

### Network Types and Communication

Learn about different types of networks and how devices communicate.

Topics include:

* LAN
* MAN
* WAN
* Ethernet
* Wi-Fi

### Servers

Learn what a server is and how it is different from a personal computer.

The course covers server types:

* Web Server
* Database Server
* Mail Server
* File Server

It also covers physical server types:

* Tower
* Rack
* Blade

### Network Devices and Internet Service

Learn about the main devices and services used to connect networks.

Topics include:

* Modem
* Router
* Gateway
* Mesh Network
* ISP

### Data Transfer and TCP

Learn how data is divided into Packets and sent through a network.

The course covers how TCP helps with packet ordering and congestion control.

### IP Addresses

Learn about IPv4 and IPv6.

The course covers:

* IPv4 — 32-bit addresses.
* IPv6 — 128-bit addresses.
* Public IP.
* Private IP.
* Static IP.
* Dynamic IP.

### DHCP and NAT

Learn how networks manage and use IP addresses.

Topics include:

* DHCP for automatic IP address assignment.
* NAT for communication between internal and external networks.
* IP Mapping.

### MAC Address, Ports, and Sockets

Learn the difference between:

* MAC Address.
* Ports.
* Sockets.

The course also covers Subnet Mask and CIDR for dividing networks.

### Internet and World Wide Web

Learn the difference between the Internet infrastructure and the World Wide Web.

The course also explains the role of web browsers in processing and translating HTML code.

### HTTP, HTTPS, and VPN

Learn the difference between HTTP and HTTPS.

The course covers HTTPS through TLS/SSL and introduces VPN for protecting connections and bypassing blocking.

### Domain Names and DNS

Learn how websites use domain names and how DNS translates domain names into IP addresses.

Topics include:

* Domain Name.
* DNS.
* Subdomains.
* Full URL components.

### FTP and API

Learn about FTP for uploading and downloading files from servers.

The course also explains APIs as a way for programs and applications to communicate with each other.

### XML, JSON, and GUID

Learn about different data formats and identifiers.

The course compares XML and JSON in terms of size, structure, and reading speed.

It also introduces GUID as a globally unique identifier.

### 3-Tier Architecture

Learn how software can be organized into three separate layers:

* Presentation Tier — User Interface.
* Business Logic Tier — Application Logic.
* Data Tier — Database.

## Key Takeaways

* Understand the basic types of computer networks.
* Understand servers and common server types.
* Understand Modems, Routers, Gateways, Mesh Networks, and ISPs.
* Understand how TCP transfers data using Packets.
* Understand IPv4, IPv6, Public, Private, Static, and Dynamic IP addresses.
* Understand DHCP, NAT, and IP Mapping.
* Understand MAC Addresses, Ports, Sockets, Subnet Masks, and CIDR.
* Understand the difference between the Internet and the World Wide Web.
* Understand HTTP, HTTPS, TLS/SSL, and VPN.
* Understand Domain Names, DNS, Subdomains, and URLs.
* Understand FTP and APIs.
* Understand XML, JSON, and GUID.
* Understand the three layers of 3-Tier Architecture.

# 2 - Algorithms & Problem Solving Level 1

## Overview

This course teaches basic algorithms and problem-solving skills. It focuses on logical thinking, problem analysis, and Flowcharts to design organized solutions.

## Main Topics

### Algorithms

Learn how to create a series of clear and ordered steps to solve a problem. The course also uses the idea of dividing a problem into smaller parts.

### Flowcharts

Learn how to use Flowcharts to show the logic and flow of a program.

The course covers the main Flowchart symbols:

* Start / End
* Input / Output
* Processes / Calculations
* Decision Making

### Problem Analysis

Learn how to divide a problem into:

* Inputs
* Processing
* Outputs

### Basic Input and Output

Practice problems that include reading user input, printing names, combining names, and calculating values.

### Conditional Statements

Practice decision-making problems such as:

* Checking Even and Odd numbers.
* Checking pass and fail results.
* Finding the largest number.
* Converting grades to letters.
* Calculating sales commissions.
* Creating a simple calculator.
* Checking valid age ranges.
* Handling ATM PIN attempts.

### Mathematical and Geometric Problems

Practice problems related to:

* Sums and averages.
* Swapping values.
* Rectangle and triangle areas.
* Circle calculations.
* Money and currency calculations.
* Bills, service fees, and sales tax.
* Time conversions.
* Loan payments.

### Loops

Practice using loops to:

* Print numbers in ascending and descending order.
* Calculate sums of even and odd numbers.
* Calculate factorials.
* Calculate powers.
* Continue calculations until a specific value is entered.
* Check for prime numbers.
* Print English letters from A to Z using ASCII values.

### Mathematical Functions

Use mathematical operations and functions such as:

* `Mod`
* `Floor`
* `sqrt`

## Key Takeaways

* Understand the basic idea of algorithms.
* Use Flowcharts to design program logic.
* Analyze problems using Inputs, Processing, and Outputs.
* Practice conditional statements and decision making.
* Practice loops and repeated operations.
* Solve mathematical and geometric problems.
* Work with time, money, bills, and loan calculations.
* Use temporary variables for operations such as `Swap`.
* Use `Mod`, `Floor`, and `sqrt` in problem solving.
* Improve logical thinking through 50 programming problems.

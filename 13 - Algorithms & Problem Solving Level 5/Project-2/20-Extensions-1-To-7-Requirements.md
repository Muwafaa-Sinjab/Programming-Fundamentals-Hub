# 20 - (Extension 1 - 6): Functions

## Overview

This project is about building and implementing a Queue class called `clsMyQueue`.

## Main Topics

### `clsMyQueue`

The `clsMyQueue` class provides the main operations for a Queue.

### Queue Operations

* `GetItem` — Get an element by its index.
* `UpdateItem` — Update an element by its index.
* `InsertAfter` — Insert an element after a specific index.
* `InsertAtFront` — Insert an element at the front.
* `InsertAtBack` — Insert an element at the back.
* `Clear` — Remove all elements.
* `Reverse` — Reverse the order of the elements.

## Key Takeaways

* `clsMyQueue` is used to implement a Queue.
* The Queue provides operations for adding, removing, accessing, and updating elements.
* The Queue also supports clearing and reversing its elements.

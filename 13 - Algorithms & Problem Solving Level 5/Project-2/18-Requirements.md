# 10 - Requirements

## Overview

This project is about building a `Queue` class called `clsMyQueue`.

## Main Topics

### `clsMyQueue`

The `clsMyQueue` class provides the main operations of a Queue.

### Queue Operations

* `push` — Add an element to the queue.
* `Print` — Print the queue elements.
* `Size` — Return the number of elements.
* `front` — Get the first element.
* `back` — Get the last element.
* `pop` — Remove the first element.

## Key Takeaways

* `clsMyQueue` represents a Queue.
* A Queue follows the FIFO principle.
* The class provides operations to add, remove, and access elements.

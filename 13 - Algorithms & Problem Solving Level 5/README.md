# 13 - Algorithms & Problem Solving Level 5

## About This Course

**Course 13 - Algorithms & Problem Solving Level 5** focuses on building and developing a **Custom Data Structures Library** from scratch using C++.

The main goal of the course is to move beyond simply using ready-made data structures. Instead, the course focuses on understanding how these structures work internally and building them step by step.

Throughout the course, data structures are created, extended, and improved through practical projects and extensions.

The course starts with linked lists and then uses them as a foundation for building other well-known data structures such as Stacks and Queues.

---

# Course Goal

The main focus of the course is to understand how data structures can be built internally instead of only using existing implementations.

The course focuses on:

* Building data structures from scratch.
* Managing data using linked structures.
* Working with pointers.
* Extending existing structures without breaking previous functionality.
* Making data structures generic using Templates.
* Applying the created structures to practical problems.

The result is a custom library of data structures that can work with different types of data.

---

# 1. Linked Lists

The course starts by building linked lists and learning how they can be used to manage data.

## Singly Linked Lists

The course includes the practical implementation of **Singly Linked Lists**.

The focus is on creating and managing the linked structure and working with pointers to connect and modify its elements.

## Doubly Linked Lists

The course also covers **Doubly Linked Lists**.

This extends the linked list concept and provides another structure for managing connected data.

The implementation focuses on working with pointers and modifying the relationships between elements.

---

# 2. Re-implementing Data Structures

After building the linked list structures, the course uses them as a foundation for creating other common data structures.

## Stack

The linked list is used to build a **Stack** structure.

The Stack supports operations for:

* Adding elements.
* Removing elements.
* Reading elements.

This provides practical experience in rebuilding a well-known data structure using a custom implementation.

## Queue

The course also uses the linked list as a foundation for building a **Queue**.

The Queue supports operations for:

* Adding elements.
* Removing elements.
* Reading elements.

This continues the idea of creating common data structures using structures built earlier in the course.

---

# 3. Extensions

A major part of the course is extending the data structures with additional features.

The purpose of these extensions is to add new functionality while keeping the previous code working.

The extensions include operations such as:

### Search

Adding the ability to search for elements inside the data structure.

### Update

Adding the ability to modify existing values.

### Reverse

Adding the ability to reverse the order of the elements.

### Delete

Adding the ability to directly remove a specific element.

### Clear

Adding the ability to remove all elements from the data structure.

### UpdateByItem

Updating a value based on the item.

### UpdateByIndex

Updating a value based on its position or index.

These extensions allow the data structures to become more complete and useful.

---

# 4. Generic Data Structures

The course also focuses on making the data structures more general.

Instead of creating the structures for only one specific data type, the course uses **Templates**.

This allows the same data structure concept to work with different types of data.

Examples include:

* Numbers.
* Strings.
* Custom objects.

This transforms the library into a more general **Generic Data Structures Library**.

---

# 5. Dynamic Undo / Redo System

The course also applies the custom data structures to a practical problem by building a **Dynamic Undo / Redo System**.

The system represents a real-world use of data structures in applications such as editors and other programs that need to return to previous operations and restore them again.

The project focuses on using the created data structures to manage:

* Undo operations.
* Redo operations.

This connects the data structures built throughout the course with a practical application.

---

# Course Progression

The course follows a progression from basic linked structures to more advanced and practical data structures.

The general progression is:

**Linked Lists → Stack → Queue → Extensions → Generic Data Structures → Undo / Redo System**

Each stage builds on the structures developed in the previous stages.

The course therefore focuses not only on creating individual data structures, but also on developing and extending a reusable custom library.

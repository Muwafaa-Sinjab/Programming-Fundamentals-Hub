# 22 : Requirements

## Overview

This project is about building a Stack class called `clsMyStack` with all the required extensions.

## Main Topics

### Basic Functions

The Stack includes these basic functions:

* `push`
* `Size`
* `top`
* `bottom`
* `pop`
* `Print`

### Extensions

The Stack also includes these extensions:

* **Extension #1** — `GetItem`
* **Extension #2** — `Reverse`
* **Extension #3** — `UpdateItem`
* **Extension #4** — `InsertAfter`
* **Extension #5** — `InsertAtFront`
* **Extension #6** — `InsertAtBack`
* **Extension #7** — `Clear`

## Key Takeaways

* `clsMyStack` provides the basic Stack functions.
* The Stack includes seven extensions.
* The extensions add more operations to the Stack.

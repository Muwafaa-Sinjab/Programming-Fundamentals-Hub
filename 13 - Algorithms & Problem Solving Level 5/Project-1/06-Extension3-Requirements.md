# 06 - (Extension 3): `Clear` Function

## Overview

This extension adds a `Clear` function to the Doubly Linked List class. The function removes all elements from the list.

## Main Topics

### `Clear`

The function takes no parameters and returns `void`.

```cpp
void Clear()
```

### Function

The function clears all elements from the list.

## Key Takeaways

* `Clear` takes no parameters.
* The return type is `void`.
* The function removes all elements from the list.

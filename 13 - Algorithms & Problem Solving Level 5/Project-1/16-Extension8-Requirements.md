# 16 - (Extension 8): `InsertAfter` Function

## Overview

This extension adds an overloaded `InsertAfter` function to the Doubly Linked List class. The function adds a new element after a specific index.

## Main Topics

### `InsertAfter`

The function takes an `Index` and a `Value`, and returns a `bool`.

```cpp
bool InsertAfter(int Index, T Value)
```

### Function

The function adds a new element with the given `Value` after the node at the given `Index`.

## Key Takeaways

* `InsertAfter` takes an `Index` and a `Value`.
* The return type is `bool`.
* The function adds a new element after the given index.

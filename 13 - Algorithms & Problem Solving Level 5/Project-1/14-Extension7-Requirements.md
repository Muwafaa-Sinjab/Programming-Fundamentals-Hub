# 14 - (Extension 7) - `UpdateItem` Function 

## Overview

This extension adds an `UpdateItem` function to the Doubly Linked List class. The function updates the value of a node at a specific index.

## Main Topics

### `UpdateItem`

The function takes an `Index` and a new `Value`, and returns a `bool`.

```cpp
bool UpdateItem(int Index, T Value)
```

### Function

The function updates the value of the node at the given index.

## Key Takeaways

* `UpdateItem` takes an `Index` and a `Value`.
* The return type is `bool`.
* The function updates the node value.

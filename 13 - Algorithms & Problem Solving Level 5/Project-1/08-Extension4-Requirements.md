# 08 - (Extension 4): `Reverse` Function

## Overview

This extension adds a `Reverse` function to the Doubly Linked List class. The function reverses the order of all elements in the list.

## Main Topics

### `Reverse`

The function takes no parameters and returns `void`.

```cpp
void Reverse()
```

### Function

The function reverses the order of all elements in the list.

## Key Takeaways

* `Reverse` takes no parameters.
* The return type is `void`.
* The function reverses the list.

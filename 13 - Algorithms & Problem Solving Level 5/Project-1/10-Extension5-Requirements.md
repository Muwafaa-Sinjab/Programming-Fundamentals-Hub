# 10 - (Extension 5): `GetNode` Function

## Overview

This extension adds a `GetNode` function to the Doubly Linked List class. The function returns the node at a specific index.

## Main Topics

### `GetNode`

The function takes an `int Index` and returns a `Node*`.

```cpp
Node* GetNode(int Index)
```

### Function

The function receives an index and returns the pointer to the node at that index.

## Key Takeaways

* `GetNode` takes an `Index` parameter.
* The return type is `Node*`.
* The function returns the node at the given index.

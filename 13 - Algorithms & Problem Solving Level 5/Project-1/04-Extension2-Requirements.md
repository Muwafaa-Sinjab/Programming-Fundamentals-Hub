# 04 - (Extension 2): `IsEmpty` Function

## Overview

This extension adds an `IsEmpty` function to the Doubly Linked List class. The function checks if the list is empty.

## Main Topics

### `IsEmpty`

The function takes no parameters and returns a `bool`.

```cpp
bool IsEmpty()
```

### Function

The function checks if the list is empty or not.

## Key Takeaways

* `IsEmpty` takes no parameters.
* The return type is `bool`.
* The function checks if the list is empty.

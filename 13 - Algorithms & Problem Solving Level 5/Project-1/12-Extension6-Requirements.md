# 12 - Extension 6: `GetItem` Function

## Overview

This extension adds a `GetItem()` function to the Doubly Linked List class. The function returns the value stored at a specific index.

## Main Topics

### `GetItem()`

The function takes an index and returns the value of the node at that index.

### Node Value

The function gets the node at the given index and returns its `Value`.

## Key Takeaways

* `GetItem()` takes an index as a parameter.
* It returns the value stored in the node.
* The return type is `T`.

# 02 - (Extension 1): `Size` Function 

## Overview

This extension adds a `Size()` function to the Doubly Linked List class. The function returns the total number of nodes in the list.

## Main Topics

### `Size()`

The `Size()` function has no parameters and returns an `int`.

```cpp
int Size()
```

### List Size

The function returns the current number of nodes in the Doubly Linked List.

## Key Takeaways

* `Size()` returns the number of nodes in the list.
* It does not take any parameters.
* The return type is `int`.

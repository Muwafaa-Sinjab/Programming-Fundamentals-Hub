# 00 - Requirements

## Overview

This project is about building a custom class called `clsDblLinkedList` to manage a **Doubly Linked List**. The class includes the required public APIs for adding, finding, deleting, and printing nodes.

## Main Topics

### Insertion

* `InsertAtBeginning(Value)` — Add a new element at the beginning.
* `InsertAtEnd(Value)` — Add a new element at the end.
* `InsertAfter(NodePointer, Value)` — Add a new node after a specific node.

### Searching

* `Find(Value)` — Find an element and return its node pointer.

### Deletion

* `DeleteNode(NodePointer)` — Delete a specific node.
* `DeleteFirstNode()` — Delete the first node.
* `DeleteLastNode()` — Delete the last node.

### Display

* `PrintList()` — Print all values in the list in order.

## Key Takeaways

* `clsDblLinkedList` manages the Doubly Linked List.
* The class provides functions for insertion, searching, deletion, and printing.
* Each operation works with the nodes and their links.

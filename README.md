# Software Engineering Learning Journey

This repository documents my software engineering learning journey through a structured **24-course learning path** focused on programming foundations, problem solving, C++, object-oriented programming, data structures, databases, C#, backend development, and systems.

The repository is not simply a list of courses. It is a record of what I studied, practiced, solved, built, and documented throughout the learning process.

For each course, there is an important distinction between:

* **What the course teaches** — the concepts, topics, and skills covered by the course.
* **What I actually did** — the work, exercises, projects, solutions, notes, or other materials that are explicitly documented in this repository.

Course content should not be interpreted as proof that I personally implemented or mastered every topic covered by a course.

# Learning Progression

The 24 courses are organized as a progressive learning path rather than a collection of unrelated subjects.

## Stage 1 — Programming Foundations & Problem Solving

**Courses 01–05**

The journey begins with the fundamentals required to understand how computers represent and process information.

It then moves into algorithmic thinking and problem decomposition before introducing C++ programming.

The progression is:

**Computer fundamentals → Algorithmic thinking → Programming → Code quality → More difficult problem solving**

The first five courses establish the basic mental models and programming habits required for more advanced work.

---

## Stage 2 — Deeper C++ & Problem Solving

**Courses 06–08**

The next stage goes deeper into C++ and increasingly difficult problem solving.

Topics expand into:

* Pointers
* References
* Dynamic memory
* Stack and heap
* File I/O
* Debugging
* Vectors and iterators
* Exception handling
* Larger problem-solving exercises
* Real projects

The difficulty and scale increase progressively, moving from individual programming problems toward larger projects and system-level thinking.

---

## Stage 3 — Systems Foundations & Object-Oriented Programming

**Courses 09–11**

After establishing programming and problem-solving foundations, the roadmap expands into how software operates within real systems.

Course 09 introduces:

* Networks
* Internet fundamentals
* TCP/IP
* DNS
* HTTP/HTTPS
* APIs
* JSON/XML
* 3-Tier Architecture
* Security fundamentals

Courses 10 and 11 then focus on object-oriented programming, first as a design concept and then through practical applications.

This creates a progression from understanding the environment in which software runs to designing and applying object-oriented systems.

---

## Stage 4 — Data Structures & Consolidation

**Courses 12–13**

Course 12 introduces fundamental data structures and complexity analysis, including:

* Big O notation
* Arrays
* Stacks
* Queues
* Linked Lists
* Singly, doubly, and circular lists
* STL fundamentals

The focus is on understanding how data can be organized and how to choose appropriate structures.

Course 13 then serves as a consolidation stage for the first part of the roadmap, focusing on larger projects, incremental expansion, maintenance-style work, and system extensions.

---

## Stage 5 — C#, Databases & Backend

**Courses 14–21**

The second major stage transitions from C++ into C# and .NET while introducing relational databases and application-database communication.

The progression is:

**C# foundations → Database design → OOP in C# → Advanced SQL → ADO.NET → Large application project → Advanced C# → T-SQL**

This stage connects programming, object-oriented design, databases, data access, and larger application development.

---

## Stage 6 — Advanced Data Structures, Algorithms & Systems

**Courses 22–24**

The final three courses in this 24-course learning path return to advanced data structures, algorithms, and system-level software.

They cover:

* Trees
* Graphs
* Heaps
* Priority queues
* Advanced collections
* Searching
* Sorting
* Binary Search Trees
* AVL trees
* DFS
* BFS
* Dijkstra
* Greedy algorithms
* Complexity analysis
* Windows Services

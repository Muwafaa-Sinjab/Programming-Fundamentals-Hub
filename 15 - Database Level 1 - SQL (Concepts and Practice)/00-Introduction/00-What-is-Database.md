# 00 - What is Database?

## Overview

This lesson explains what a database is and how it is used to store and manage data. It also introduces DBMS, RDBMS, and basic database terms.

## Main Topics

### Database and DBMS

A **Database** is an organized collection of data.

A **DBMS** is software used to create, manage, and control databases.

### Types of DBMS

There are two main types:

* **Non-Relational DBMS** — Stores data without traditional relations between tables.
* **Relational DBMS (RDBMS)** — Stores data in tables with rows, columns, and relations.

Examples of RDBMS include SQL Server, Oracle, MySQL, and PostgreSQL.

### RDBMS Terms

* **Table** — A set of data about an entity.
* **Column** — A field or attribute of the entity.
* **Row** — A complete record of one entity.

### RDBMS Design

Data can be divided into different tables and connected using a common field such as `DepartmentID`.

## Key Takeaways

* A database stores organized data.
* DBMS is used to manage databases.
* RDBMS stores data in tables.
* Tables contain rows and columns.
* Tables can be connected using related fields.

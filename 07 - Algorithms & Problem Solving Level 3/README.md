# 07 - Algorithms & Problem Solving Level 3

## Overview

This course provides 51 C++ programming problems and solutions. It focuses on 2D arrays, Fibonacci, strings, character manipulation, files, and data records.

## Main Topics

### 2D Arrays and Matrices

Learn how to work with two-dimensional arrays and matrices.

Topics include:

* Creating random and ordered matrices.
* Calculating row and column sums.
* Multiplying matrices.
* Identity Matrix.
* Scalar Matrix.
* Sparse Matrix.
* Checking matrix Palindrome.
* Finding intersections between two matrices.

### Fibonacci Series

Learn how to solve the Fibonacci Series using:

* Loops.
* Recursion.

### Strings and Character Manipulation

Learn how to process strings and characters.

Topics include:

* Changing letters to Uppercase.
* Changing letters to Lowercase.
* Inverting letter case.
* Counting words.
* Counting Vowels.
* Splitting strings.
* Joining strings.
* Trimming spaces.
* Removing punctuation.

### Files and Structs

Learn how to manage data records using Structs and text files.

The course covers:

* Converting records to text lines.
* Converting text lines back to records.
* Saving customer data.
* Reading customer data.
* Searching for customer records.
* Updating customer records.
* Deleting customer records.
* Working with `Clients.txt`.

## Key Takeaways

* Solve 51 C++ programming problems.
* Work with 2D Arrays and Matrices.
* Perform matrix calculations and comparisons.
* Work with Identity, Scalar, and Sparse Matrices.
* Solve Fibonacci using Loops and Recursion.
* Manipulate strings and characters.
* Count words and Vowels.
* Split, Join, and Trim strings.
* Remove punctuation from text.
* Store and manage customer records in text files.
* Read, search, update, and delete customer data.

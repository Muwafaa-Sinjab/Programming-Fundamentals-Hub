# 4 - Advanced Solutions for Algorithms & Problem Solving Level 1

## Overview

This course provides solutions for 50 algorithm and problem-solving problems using C++. It focuses on breaking problems into smaller tasks using Functions and Procedures. It also focuses on clean code and testing different input cases.

## Main Topics

### Problem Solving with Functions and Procedures

Learn how to divide large problems into smaller tasks using Functions and Procedures. This helps make the code easier to manage and maintain.

### Pass by Reference

Learn how to use `&` to read and change the original variable directly. The `Swap` problem is one example of this approach.

### Testing Input Cases

Learn the importance of testing accepted inputs and wrong or edge cases to help keep the program stable.

### Enumerations

Use `enum` to organize different options and types, such as:

* `Odd / Even`
* `Pass / Fail`
* Days of the week
* Mathematical operations

### Structures

Use `struct` to group related data into one structure.

Examples include:

* Person information.
* Cash information.
* Task time information.

### Mathematical Functions

Use functions from `<cmath>` in mathematical and geometric problems:

* `pow()`
* `sqrt()`
* `round()`
* `floor()`

### Input, Output, and Text Problems

Practice problems that include:

* Printing names.
* Using `getline()`.
* Combining and reversing names.
* Simple calculations.
* Data type conversion.

### Conditions and Decision Making

Practice problems that include:

* Checking age, driving license, and assistance.
* Converting grades from `A` to `F`.
* Calculating sales commissions.
* Checking valid age ranges from 18 to 45.
* Repeating input until a valid value is entered.

### Mathematical and Geometric Problems

Practice problems involving:

* Rectangle, triangle, and circle areas.
* Circle calculations using radius, diameter, and perimeter.
* Circles inside squares or triangles.
* Powers such as `N²`, `N³`, and `N⁴`.
* Calculating `N^M` using repetition.

### Loops and Repetition

Use:

* `for`
* `while`
* `do-while`

The problems include printing numbers, calculating even and odd sums, calculating Factorial, and repeating operations.

### Calculator and Prime Numbers

Practice building a calculator using `switch` and checking Prime Numbers.

The course also includes printing letters from `A` to `Z` using ASCII.

### Real-World Problems

Practice problems related to:

* Time conversions between hours, days, weeks, and seconds.
* Cash and money calculations.
* Bills with 16% tax and 10% service.
* Monthly loan payments.
* ATM PIN verification with three attempts.

## Key Takeaways

* Solve 50 algorithm and problem-solving problems using C++.
* Divide problems into smaller tasks using Functions and Procedures.
* Use Pass by Reference to change original variables.
* Use `enum` to organize different options and types.
* Use `struct` to group related data.
* Use mathematical functions from `<cmath>`.
* Work with conditions, loops, text, and calculations.
* Build a simple calculator using `switch`.
* Check Prime Numbers and work with ASCII values.
* Solve practical problems involving time, money, bills, loans, and ATM PIN verification.
* Test different input cases, including wrong and edge cases.
* Practice writing cleaner and easier-to-maintain code.

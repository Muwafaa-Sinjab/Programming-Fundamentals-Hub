# 05 - Algorithms & Problem-Solving – Level 2

## Overview

This course provides 50 C++ programming problems and exercises. It focuses on using Procedures and Functions to divide problems into smaller parts. The course also covers numbers, strings, arrays, random generation, encryption, and custom math functions.

## Main Topics

### Numbers and Mathematical Operations

Practice different problems with numbers and calculations.

Topics include:

* Printing multiplication tables from 1 to 10.
* Creating number and letter patterns.
* Printing patterns in normal and reversed forms.
* Checking and printing Prime Numbers within a range.
* Finding Perfect Numbers.
* Checking Palindrome Numbers.

### Digits

Learn how to work with the digits of a number.

Topics include:

* Printing digits in reverse order.
* Printing digits in the original order.
* Finding the sum of digits.
* Counting a specific digit.
* Counting all digits in a number.

### Strings and Characters

Practice working with characters and strings.

Topics include:

* Generating uppercase letter combinations from `AAA` to `ZZZ`.
* Trying to find a three-letter password.
* Generating random letters and symbols.

### Encryption and Decryption

Learn how to encrypt and decrypt text using letter shifting.

### Random Generation

Practice generating:

* Random numbers.
* Random letters.
* Random symbols.
* Random keys with specific formats.

### Arrays

Learn different ways to work with arrays.

Topics include:

* Reading and printing array elements.
* Filling arrays with random numbers.
* Filling arrays with ordered numbers.
* Finding the largest and smallest elements.
* Calculating the sum and average.
* Counting odd and even numbers.
* Counting positive and negative numbers.

### Array Copying and Filtering

Practice moving and copying array elements.

Topics include:

* Copying a complete array.
* Copying an array in reverse order.
* Copying only Prime or Odd elements.

### Array Search and Processing

Practice more advanced array operations.

Topics include:

* Searching for an element and returning its position.
* Adding array elements dynamically using `AddArrayElement`.
* Removing duplicate elements.
* Shuffling array elements randomly.
* Checking if an array is a Palindrome.

### Custom Math Functions

Rebuild basic mathematical functions without using ready-made math libraries.

The course includes:

* `MyABS` — Absolute value.
* `MyRound` — Rounding.
* `MyFloor` — Rounding down.
* `MyCeil` — Rounding up.
* `MySqrt` — Square root.

## Key Takeaways

* Solve 50 C++ programming problems and exercises.
* Use Procedures and Functions to divide problems into smaller parts.
* Work with numbers, digits, and mathematical operations.
* Check Prime, Perfect, and Palindrome Numbers.
* Work with strings, characters, encryption, and decryption.
* Generate random numbers, letters, symbols, and keys.
* Work with arrays and perform different calculations on their elements.
* Search, copy, filter, shuffle, and remove duplicate array elements.
* Check if arrays are Palindromes.
* Build basic math functions without using ready-made math libraries.

# 03 - Things Affect Program Speed & Efficiency

## Overview

This lesson explains what makes a program fast or slow. It talks about the Algorithm and the Hardware. It shows what a developer should focus on to improve a program.

## Main Topics

### Algorithm Factors

The algorithm affects the speed of the program. The algorithm uses two main resources:

- **Time:** The time the program takes to run. This is called Time Complexity.
- **Space:** The memory the algorithm uses. This is called Space Complexity.

Both time and space affect the algorithm's quality.

### Hardware Factors

The hardware also affects the speed of the program. This is called Performance. Hardware factors include:

- CPU
- RAM
- Operating System (OS)

### Developer Focus

A developer usually cannot change the hardware. The developer must focus on writing a better algorithm. By improving the algorithm, the developer reduces Time Complexity and Space Complexity. This makes the program faster and use less memory.

## Key Takeaways

- Program speed depends on the Algorithm and the Hardware.
- Algorithms use Time and Space.
- Hardware includes CPU, RAM, and OS.
- A developer should focus on improving the Algorithm.
- Better Time and Space Complexity make a better program.

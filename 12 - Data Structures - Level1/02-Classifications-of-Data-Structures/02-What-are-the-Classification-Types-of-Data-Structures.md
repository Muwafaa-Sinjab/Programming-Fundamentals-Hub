# 02 - What are the Classification/Types of Data Structures?

## Overview

This lesson explains the types of data structures. It divides them into Primitive and Non-Primitive. It also explains the difference between Linear and Non-Linear data structures.

## Main Topics

### Primitive Data Structures

These are the most basic types. They are simple and built into the language. Examples are **`int`**, **`float`**, **`char`**, and **`pointer`**. The language uses machine instructions to handle them. They are easy to define, like **`int X = 10;`**.

### Non-Primitive Data Structures

These are complex types. They are built using Primitive data structures. They are divided into two main groups: Linear and Non-Linear.

### Linear Data Structures

In a linear data structure, data is in a sequence. You can access all items using one **`for loop`**. Linear types have two sub-groups:

- **Static Data Structure:** The memory size is fixed. You cannot change the size at runtime. Example: Array. It is fast to access items.
- **Dynamic Data Structure:** The memory size is not fixed. You can change the size at runtime. Examples: Vector, Stack, Queue, Linked List.

### Non-Linear Data Structures

In a non-linear data structure, data is not in a sequence. You cannot access all items using one **`for loop`**. Examples: Tree, Graph.

### Homogeneous vs Heterogeneous

- **Homogeneous:** The data structure has only one type of data. Example: Array (all items are **`int`**).
- **Heterogeneous:** The data structure has different types of data. Examples: Tree, Graph.

### Operations on Data Structures

You can do these operations on data structures:

1. Create
2. Update
3. Search
4. Select
5. Sorting
6. Merging
7. Delete
8. Destroy

## Key Takeaways

- Primitive types are simple (like **`int`**, **`char`**).
- Non-Primitive types are complex and built from Primitive types.
- Linear data structures have data in a sequence.
- Non-Linear data structures do not have data in a sequence.
- Static data structures have a fixed size. Dynamic data structures can change size.

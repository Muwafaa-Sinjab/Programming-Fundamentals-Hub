# 12 - Data Structures – Level 1

## Overview

This course introduces the basic concepts of Data Structures. It covers data organization, Big O analysis, arrays, stacks, queues, linked lists, Abstract Data Types, maps, and unions.

## Main Topics

### Data Structures Foundations

Learn the basic meaning of Data Structures and how they organize data in RAM to improve program efficiency.

The course also compares Data Structures with Databases and covers different classifications:

* Primitive types: `int`, `float`, `char`, and pointers.
* Non-Primitive types: Arrays, Linked Lists, Stacks, Queues, Trees, and Graphs.
* Linear and Non-Linear structures.
* Static and Dynamic structures.
* Homogeneous and Heterogeneous structures.

### Big O Notation

Learn how to analyze the performance of algorithms using Big O notation.

The course covers:

* `O(1)` — Constant Time.
* `O(log n)` — Logarithmic Time.
* `O(n)` — Linear Time.
* `O(n²)` — Quadratic Time.

### Arrays and Matrices

Learn about arrays and matrices as static linear data structures with direct access to elements using indexes.

### Stacks

Learn about Stacks and the Last-In, First-Out (LIFO) structure.

The course covers basic Stack operations:

* `push`
* `pop`
* `top`

### Queues

Learn about Queues and the First-In, First-Out (FIFO) structure.

The course covers basic Queue operations:

* `push`
* `pop`
* `front`
* `back`

### Linked Lists

Learn about dynamic linear structures made of nodes that store data and pointers.

The course covers:

* Singly Linked Lists using `Next`.
* Doubly Linked Lists using `Next` and `Prev`.
* Circular Linked Lists where the last node points back to the first node.
* CRUD operations for Linked Lists.

### Abstract Data Types

Learn about Abstract Data Types (ADT) and how they hide the internal implementation while providing public operations.

### Maps and Dictionaries

Learn about `std::map` as a key-value container with keys sorted automatically in ascending order.

### Unions

Learn about Unions as user-defined types where all members share the same memory location.

## Key Takeaways

* Understand the basic concepts and classifications of Data Structures.
* Understand the difference between Data Structures and Databases.
* Analyze algorithm performance using Big O notation.
* Understand `O(1)`, `O(log n)`, `O(n)`, and `O(n²)`.
* Work with Arrays and Matrices.
* Understand Stacks and the LIFO structure.
* Understand Queues and the FIFO structure.
* Work with Singly, Doubly, and Circular Linked Lists.
* Understand CRUD operations for Linked Lists.
* Understand Abstract Data Types.
* Work with `std::map` for key-value data.
* Understand how Unions share memory between their members.

# 01 - Differences between Data Structures and Database

## Overview

This lesson explains the difference between Data Structures and Databases. It compares where they store data, how long they keep it, and what tools we use to manage them.

## Main Topics

### Data Structure

A data structure stores data inside the program. The data is kept in the RAM. This means the data is temporary. When you close the program, you cannot get the data back. We use programming languages like C++ or Python to work with data structures.

### Database

A database stores data outside the program. The data is kept on the Hard Disk or a Server. This means the data is permanent. When you close the program, the data is still there. A database stores data in tables (rows and columns). We use SQL (Structured Query Language) to manage the data. We use a DBMS (Database Management System) like MySQL or Oracle to handle the database.

### Comparison Summary

- **Storage Location:** Data Structures use RAM. Databases use Hard Disk.
- **Data Life:** Data Structures are temporary. Databases are permanent.
- **Data Shape:** Data Structures are organized for program efficiency. Databases are organized in tables.
- **Tools Used:** Data Structures use languages like C++. Databases use SQL and DBMS.

## Key Takeaways

- Data structures store data in RAM (temporary).
- Databases store data on the Hard Disk (permanent).
- When a program closes, data in the data structure is lost.
- Databases keep data even after the program closes.
- We use programming languages for data structures, and SQL for databases.

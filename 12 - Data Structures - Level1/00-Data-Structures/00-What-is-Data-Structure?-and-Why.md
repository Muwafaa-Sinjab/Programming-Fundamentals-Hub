# 00 - What is Data Structure? and Why?

## Overview

This lesson explains what a data structure is. It shows why data structures are important in programming. It introduces the basic equation of a program: Program = Algorithms + Data Structure.

## Main Topics

### What is a Program?

A program has two main parts. These parts are Algorithms and Data Structure.

`Program = Algorithms + Data Structure`

### What is an Algorithm?

An algorithm is the steps to solve a problem. It is the logic of the program. These steps use tools like **`if`**, **`for`**, and **`while`**. These tools are part of the programming language.

### What is a Data Structure?

A data structure is a way to organize data inside a program. It stores data in the memory (RAM) while the program runs. It helps the program access, process, and retrieve data very fast and efficiently.

A data structure is not just for storing data. It also defines the relationships between data items. Choosing the right data structure affects the design of the program. It affects both the structure and the function of the program.

## Key Takeaways

* A program is made of Algorithms and Data Structures.
* An algorithm is the step-by-step solution to a problem.
* A data structure organizes and stores data inside the program.
* Good data structures make programs fast and efficient.
* Data structures affect the design of the program.

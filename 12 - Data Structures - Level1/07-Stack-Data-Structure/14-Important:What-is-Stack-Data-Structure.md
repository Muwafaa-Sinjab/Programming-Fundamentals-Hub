# 14 - Important: What is Stack Data Structure?

## Overview
This lesson introduces the Stack data structure. It explains the LIFO principle (Last In First Out). It also describes the basic operations of a Stack and its real-world uses.

## Main Topics
### What is a Stack?
A Stack is a linear data structure. It follows the **LIFO** principle. LIFO stands for **Last In First Out**. This means the last element you add to the Stack is the first element you remove from it. You can think of it like a stack of plates. You put a new plate on top, and you take the top plate first.

### Stack Operations
There are two main operations in a Stack:

- **Push**: This operation adds an element to the top of the Stack.
- **Pop**: This operation removes the top element from the Stack.

You cannot remove an element from the bottom or the middle. You can only remove the top element. You also cannot access elements directly by index like in an Array.

### Stack Base
A Stack is built on top of other data structures. It can be built using an Array or a Vector.

### Real-World Use: Call Stack
A very important use of the Stack is the **Call Stack** in programming. When a program calls a function, it is pushed onto the Call Stack. When the function finishes, it is popped off the Call Stack. This is also called Function Call Hierarchy.

## Key Takeaways
- A Stack follows the LIFO principle (Last In First Out).
- The last item added is the first item removed.
- Push adds an item to the top of the Stack.
- Pop removes the top item from the Stack.
- Stacks are used in programming for the Call Stack.

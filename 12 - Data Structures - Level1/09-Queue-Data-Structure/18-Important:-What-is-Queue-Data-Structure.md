# 18 - Important: What is Queue Data Structure?

## Overview
This lesson introduces the Queue data structure. It explains the FIFO principle (First In First Out). It also compares Queue to Stack.

## Main Topics
### What is a Queue?
A Queue is a linear data structure. It follows the **FIFO** principle. FIFO stands for **First In First Out**. This means the first element you add to the Queue is the first element you remove. You can think of it like a line of people. The first person in the line is the first person served.

### Queue Operations
There are two main operations in a Queue:

- **Push (Enqueue)**: This operation adds an element to the back (end) of the Queue.
- **Pop (Dequeue)**: This operation removes the element from the front of the Queue.

### Queue vs Stack
A Queue is the opposite of a Stack:

- **Queue**: Uses FIFO (First In First Out). The first item added is the first removed.
- **Stack**: Uses LIFO (Last In First Out). The last item added is the first removed.

## Key Takeaways
- A Queue follows the FIFO principle (First In First Out).
- The first item added to the Queue is the first item removed.
- Push adds an item to the back of the Queue.
- Pop removes an item from the front of the Queue.
- Queue is the opposite of Stack.

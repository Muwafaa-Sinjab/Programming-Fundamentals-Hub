# 40 - What is ADT?

## Overview
This lesson introduces the concept of an Abstract Data Type (ADT). It explains what an ADT is and how it separates the definition of operations from the actual implementation.

## Main Topics
### What is an ADT?
ADT stands for **Abstract Data Type**. An ADT is a mathematical model for a data type. It defines the data type by its behavior. This means it defines **what** operations can be performed, but it does **not** define **how** these operations are implemented.

### Operations and Implementation
For an ADT, the user only knows the available operations and what they do. The user does not know how the data is stored in memory or how the operations are written in code. This is called "hiding the implementation details."

For example, a Stack is an ADT. You know you can push and pop items. You do not need to know if the Stack is built using an Array or a Linked List.

## Key Takeaways
- ADT stands for Abstract Data Type.
- An ADT defines operations but hides the implementation.
- The user only cares about what the ADT does, not how it does it.
- Stack and Queue are examples of ADTs.
